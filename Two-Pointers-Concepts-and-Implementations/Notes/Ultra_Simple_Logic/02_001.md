# Lesson 2: Remove Duplicates from Sorted Array (#001)

Previous lesson: #053 Valid Palindrome

## Mental model
Read each element; write only when it differs from the last accepted value.

## Explain the logic in small steps
1. The array is sorted, so equal numbers sit together.
2. write tells us where the next unique number belongs.
3. read examines every original value. It never moves backward.
4. If write is zero, accept the first value. Otherwise compare with the last accepted value at write - 1.
5. Copy a new value and increase write. Skip a duplicate without increasing write.
6. Return write, not the entire array. Only the first write entries are the answer.

## Example
Example: 1,1,2 -> 1,2

## Complexity
Time: O(n). Auxiliary space: O(1).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

## C
[C annotated source](../../C/Ultra_Simple_Commented/001_Remove_Duplicates_from_Sorted_Array.c)

```c
// Remove Duplicates from Sorted Array
// Keep a write position. Copy each new value there. The sorted order puts duplicates together.
// O(n) time, O(1) extra space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
int solve(int *a, int n) {
    int write = 0;
    for (int read = 0; read < n; read++) {
        if (write == 0 || a[read] != a[write-1])
            a[write++] = a[read];
    }
    return write;
}
```

```python
# Remove Duplicates from Sorted Array
# Keep a write position. Copy each new value there. The sorted order puts duplicates together.
# O(n) time, O(1) extra space
def solve(a):
    write = 0
    for value in a:
        if write == 0 or value != a[write-1]:
            a[write] = value
            write += 1
    return write
```
