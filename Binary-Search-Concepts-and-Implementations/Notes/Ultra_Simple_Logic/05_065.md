# Lesson 5: Fixed Point (#065)

Previous lesson: #059 Find First and Last Position

## Mental model
For distinct sorted integers, compare value with index; search first index where value minus index is nonnegative; verify equality.

## Explain the logic in small steps
1. The array contains distinct sorted integers.
2. Because successive values increase by at least one, value minus index never decreases.
3. If a[mid] is smaller than mid, every earlier difference is negative too. Move low right.
4. Otherwise keep mid as a possible first nonnegative difference.
5. At the end, check that the index exists and a[low] equals low. Return -1 if not.

## Example
Example: -1,0,2,4 -> 2

## Complexity
Time: O(log n). Auxiliary space: O(1).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

```c
// Fixed Point
// For distinct sorted integers, a[i]-i cannot decrease. Search for zero.
// O(log n) time, O(1) space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
int solve(int *a,int n) {
    int low=0,high=n;
    while(low<high) {
        int mid=low+(high-low)/2;
        if(a[mid]<mid) low=mid+1; else high=mid;
    }
    return low<n && a[low]==low ? low : -1;
}
```

```python
# Fixed Point
# For distinct sorted integers, a[i]-i cannot decrease. Search for zero.
# O(log n) time, O(1) space
def solve(a):
    low,high=0,len(a)
    while low<high:
        mid=low+(high-low)//2
        if a[mid]<mid: low=mid+1
        else: high=mid
    return low if low<len(a) and a[low]==low else -1
```
