# Lesson 2: Middle of the Linked List (#033)

Previous lesson: #031 Reverse Linked List

## Mental model
Move slow one step and fast two; slow reaches middle when fast reaches end.

## Explain the logic in small steps
1. Start slow and fast at the head.
2. Move slow one link whenever fast can move two links.
3. Fast covers twice the distance of slow.
4. When fast reaches the end or cannot move two links, slow is at the middle.
5. For an even number of nodes this returns the second middle. For an empty list it returns an empty pointer.

## Example
Example: 1->2->3 -> 2

## Complexity
Time: O(n). Auxiliary space: O(1).

```c
// Middle of the Linked List
// Slow moves one step. Fast moves two. When fast reaches the end, slow is at the middle (second middle for even length).
// O(n) time, O(1) space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
typedef struct Node { int val; struct Node *next; } Node;
Node *solve(Node *head) {
    Node *slow=head,*fast=head;
    while(fast && fast->next) {slow=slow->next;fast=fast->next->next;}
    return slow;
}
```

```python
# Middle of the Linked List
# Slow moves one step. Fast moves two. When fast reaches the end, slow is at the middle (second middle for even length).
# O(n) time, O(1) space
class Node:
    def __init__(self,val=0,next=None):
        self.val=val
        self.next=next

def solve(head):
    slow=fast=head
    while fast and fast.next:
        slow=slow.next
        fast=fast.next.next
    return slow
```
