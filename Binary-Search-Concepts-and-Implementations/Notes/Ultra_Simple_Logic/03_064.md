# Lesson 3: Upper Bound (#064)

Previous lesson: #058 Search Insert Position

## Mental model
Change lower-bound comparison to find first value strictly greater than target.

## Explain the logic in small steps
1. Reuse the insertion-position search.
2. The only change is that values equal to target must also be skipped.
3. If a[mid] is less than or equal to target, move low to mid + 1.
4. Otherwise keep mid by setting high to mid.
5. Return the first strictly greater index, or -1 if none exists. This pack uses -1 rather than n.

## Example
Example: 1,2,2,4 target 2 -> 3

## Complexity
Time: O(log n). Auxiliary space: O(1).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

```c
// Upper Bound
// Find the first value strictly greater than target.
// O(log n) time, O(1) space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
int solve(int *a,int n,int target) {
    int low=0,high=n;
    while(low<high) {
        int mid=low+(high-low)/2;
        if(a[mid] <= target) low=mid+1;
        else high=mid;
    }
    return low<n ? low : -1;
}
```

```python
# Upper Bound
# Find the first value strictly greater than target.
# O(log n) time, O(1) space
def solve(a,target):
    low,high=0,len(a)
    while low<high:
        mid=low+(high-low)//2
        if a[mid] <= target: low=mid+1
        else: high=mid
    return low if low < len(a) else -1
```
