# Lesson 7: Trapping Rain Water (#004)

Previous lesson: #003 Container With Most Water

## Mental model
Maintain left and right maximum heights; process the side with smaller maximum; add maximum minus current height.

## Explain the logic in small steps
1. Keep the largest wall seen from each side, initially zero.
2. Process the side with the smaller known maximum. A wall on the other side is already high enough to support that level.
3. If the current wall is taller than its known maximum, update that maximum.
4. Subtract the current height from the updated maximum. This is the water above the current position, possibly zero.
5. Move only the processed pointer. Each position contributes once.
6. Return the sum of these individual water amounts.

## Example
Example: 5,1,2,4 -> 5

## Complexity
Time: O(n). Auxiliary space: O(1).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

// Trapping Rain Water
// Track the highest wall seen from each side. Process the side with the smaller known maximum. Its water level is already determined.
// O(n) time, O(1) space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
long long solve(int *a,int n) {
    int left=0,right=n-1,lm=0,rm=0;
    long long water=0;
    while(left<=right) {
        if(lm<=rm) {
            if(a[left]>lm) lm=a[left];
            water+=lm-a[left++];
        } else {
            if(a[right]>rm) rm=a[right];
            water+=rm-a[right--];
        }
    }
    return water;
}
```

# Trapping Rain Water
# Track the highest wall seen from each side. Process the side with the smaller known maximum. Its water level is already determined.
# O(n) time, O(1) space
def solve(a):
    left, right = 0, len(a)-1
    lm = rm = water = 0
    while left <= right:
        if lm <= rm:
            lm = max(lm, a[left])
            water += lm-a[left]
            left += 1
        else:
            rm = max(rm, a[right])
            water += rm-a[right]
            right -= 1
    return water
```
