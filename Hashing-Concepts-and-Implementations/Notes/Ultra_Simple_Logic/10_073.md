# Lesson 10: Majority Element (#073)

Previous lesson: #072 Missing Element Limited Memory

## Mental model
Maintain candidate and vote balance; cancel different values; verify candidate if majority not guaranteed.

## Explain the logic in small steps
1. Assume a majority value occurs more than half the time.
2. candidate is the current possible majority. count is its unmatched vote count.
3. When count is zero, choose the current value as the new candidate.
4. Increase count for a matching value. Decrease it for a different value.
5. Each cancellation removes two different values, so a guaranteed majority cannot be eliminated completely.
6. Return the surviving candidate. Without a guaranteed majority, a second verification pass is needed.

## Example
Example: 2,2,1 -> 2

## Complexity
Time: O(n). Auxiliary space: O(1).

Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

```c
// Majority Element
// Cancel two different values. A guaranteed majority survives all cancellations.
// O(n) time, O(1) space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
int solve(int *a,int n) {
    int candidate=0,count=0;
    for(int i=0;i<n;i++) {
        if(count==0) candidate=a[i];
        if(a[i]==candidate) count++; else count--;
    }
    return candidate;
}
```

```python
# Majority Element
# Cancel two different values. A guaranteed majority survives all cancellations.
# O(n) time, O(1) space
def solve(a):
    count=0
    candidate=None
    for value in a:
        if count==0: candidate=value
        if value==candidate: count+=1
        else: count-=1
    return candidate
```
