# Lesson 1: Longest Substring Without Repeating Characters (#005)

Starting foundation.

## Mental model
Expand right; remember last index of each character; move left past a repeated character if it is inside the window.

## Explain the logic in small steps
1. left marks the start of a window without duplicates.
2. right reads one new character at a time.
3. Remember the most recent index of each character. An unseen character has index -1.
4. If the previous occurrence is inside the window, move left just past it. Never move left backward.
5. Record the new last index and compute right - left + 1.
6. Keep the largest valid length.

## Example
Example: abcabcbb -> 3

## Complexity
Time: O(n). Auxiliary space: O(alphabet).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

// Longest Substring Without Repeating Characters
// Remember the last index of each character. If it is inside the window, move left past it. Update the longest length. ASCII input.
// O(n) time, O(1) space for fixed alphabet
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
int solve(const char *s) {
    int last[256],left=0,best=0;
    for(int i=0;i<256;i++) last[i]=-1;
    for(int right=0;s[right];right++) {
        unsigned char ch=s[right];
        if(last[ch]>=left) left=last[ch]+1;
        last[ch]=right;
        if(right-left+1>best) best=right-left+1;
    }
    return best;
}
```

# Longest Substring Without Repeating Characters
# Remember the last index of each character. If it is inside the window, move left past it. Update the longest length. ASCII input.
# O(n) time, O(1) space for fixed alphabet
def solve(s):
    last={}
    left=best=0
    for right,ch in enumerate(s):
        left=max(left,last.get(ch,-1)+1)
        last[ch]=right
        best=max(best,right-left+1)
    return best
```
