# Lesson 1: Valid Palindrome (#053)

Starting foundation.

## Mental model
Compare opposite characters; skip non-alphanumeric characters; move inward after a match.

## Explain the logic in small steps
1. Start with one pointer at each end.
2. Skip punctuation on either side. It is not part of the comparison.
3. Convert the two remaining characters to lowercase before comparing.
4. If they differ, the string cannot be a palindrome.
5. If they match, move both pointers inward. Those characters need no further checking.
6. When the pointers meet or cross, every required pair has matched.

## Example
Example: A man, a plan, a canal: Panama -> true

## Complexity
Time: O(n). Auxiliary space: O(1).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

// Valid Palindrome
// Skip punctuation at both ends. Compare lowercase letters or digits. Move inward after a match.
// O(n) time, O(1) space (ASCII input)
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
bool solve(const char *s) {
    int left=0,right=(int)strlen(s)-1;
    while(left<right) {
        if(!isalnum((unsigned char)s[left])) left++;
        else if(!isalnum((unsigned char)s[right])) right--;
        else if(tolower((unsigned char)s[left])!=tolower((unsigned char)s[right])) return false;
        else {left++;right--;}
    }
    return true;
}
```

# Valid Palindrome
# Skip punctuation at both ends. Compare lowercase letters or digits. Move inward after a match.
# O(n) time, O(1) space (ASCII input)
def solve(s):
    left,right=0,len(s)-1
    while left<right:
        if not s[left].isalnum(): left+=1
        elif not s[right].isalnum(): right-=1
        elif s[left].lower()!=s[right].lower(): return False
        else: left+=1;right-=1
    return True
```
