# Lesson 2: Search Insert Position (#058)

Previous lesson: #062 Binary Search

## Mental model
Find the first index whose value is at least target using a half-open interval.

## Explain the logic in small steps
1. Reuse the half-open binary search range.
2. If a[mid] is smaller than target, move low past mid.
3. Otherwise keep mid as a possible insertion position by moving high to mid.
4. Stop when the two boundaries meet.
5. Return low even if target is absent. It is where target belongs in sorted order.

## Example
Example: 1,3,5,6 target 2 -> 1

## Complexity
Time: O(log n). Auxiliary space: O(1).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

```c
// Search Insert Position
// Find the first position whose value is at least target.
// O(log n) time, O(1) space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
int solve(int *a,int n,int target) {
    int low=0,high=n;
    while(low<high) {
        int mid=low+(high-low)/2;
        if(a[mid] < target) low=mid+1;
        else high=mid;
    }
    return low;
}
```
