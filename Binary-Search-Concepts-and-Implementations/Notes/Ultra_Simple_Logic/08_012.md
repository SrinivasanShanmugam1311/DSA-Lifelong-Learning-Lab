# Lesson 8: Find Minimum in Rotated Sorted Array (#012)

Previous lesson: #011 Search in Rotated Sorted Array

## Mental model
Compare middle with rightmost value; minimum is in right half if middle is greater, otherwise keep middle and left half.

## Explain the logic in small steps
1. The rotated array contains distinct values and is nonempty.
2. Compare the middle value with the rightmost value.
3. If middle is greater, the rotation minimum must lie strictly to its right.
4. Otherwise the minimum is at middle or somewhere to its left. Keep middle.
5. Stop when one candidate remains. Return its value, not its index.

## Example
Example: 3,4,5,1,2 -> 1

## Complexity
Time: O(log n) distinct values. Auxiliary space: O(1).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

```c
// Find Minimum in Rotated Sorted Array
// Compare middle with the right end. If middle is larger, minimum is to its right. Otherwise keep middle. Distinct elements assumed.
// O(log n) time, O(1) space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
int solve(int *a,int n) {
    int low=0,high=n-1;
    while(low<high) {
        int mid=low+(high-low)/2;
        if(a[mid]>a[high]) low=mid+1;
        else high=mid;
    }
    return a[low];
}
```

```python
# Find Minimum in Rotated Sorted Array
# Compare middle with the right end. If middle is larger, minimum is to its right. Otherwise keep middle. Distinct elements assumed.
# O(log n) time, O(1) space
def solve(a):
    low,high=0,len(a)-1
    while low<high:
        mid=low+(high-low)//2
        if a[mid]>a[high]: low=mid+1
        else: high=mid
    return a[low]
```
