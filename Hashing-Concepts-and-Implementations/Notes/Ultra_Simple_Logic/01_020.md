# Lesson 1: Valid Anagram (#020)

Starting foundation.

## Mental model
Count letters in first string and subtract second; all counts must be zero.

## Explain the logic in small steps
1. Use 26 counters for lowercase English letters.
2. Convert each character into an index from 0 to 25.
3. Add one for every letter in the first word.
4. Subtract one for every letter in the second word.
5. If any count is nonzero, the words contain different letter frequencies.
6. If all counts are zero, the words are anagrams.

## Example
Example: anagram,nagaram -> true

## Complexity
Time: O(n+m). Auxiliary space: O(alphabet).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

// Valid Anagram
// Count letters in the first string. Subtract letters in the second. Every count must end at zero. Lowercase English letters assumed.
// O(n+m) time, O(1) space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
bool solve(const char *s,const char *t) {
    int count[26]={0};
    for(;*s;s++) count[*s-'a']++;
    for(;*t;t++) count[*t-'a']--;
    for(int i=0;i<26;i++) if(count[i]!=0) return false;
    return true;
}
```

# Valid Anagram
# Count letters in the first string. Subtract letters in the second. Every count must end at zero. Lowercase English letters assumed.
# O(n+m) time, O(1) space
def solve(s,t):
    count=[0]*26
    for ch in s: count[ord(ch)-97]+=1
    for ch in t: count[ord(ch)-97]-=1
    return all(x==0 for x in count)
```
