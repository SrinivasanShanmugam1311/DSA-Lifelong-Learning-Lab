# Lesson 7: Sliding Window Maximum (#010)

Previous lesson: #009 Minimum Window Substring

## Mental model
Keep indices in a decreasing deque; remove expired indices from front and smaller values from back; front is maximum.

## Explain the logic in small steps
1. Keep indices in a decreasing deque.
2. Remove expired indices from front and smaller values from back.
3. Front is maximum.

## Example
Example: 1,3,-1,-3,5,3,6,7 k=3 -> 3,3,5,5,6,7

## Complexity
Time: O(n). Auxiliary space: O(k).
