# Lesson 6: Container With Most Water (#003)

Previous lesson: #002 3Sum

## Mental model
Compute width times shorter height; save maximum; move the shorter wall.

## Explain the logic in small steps
1. Start with the widest possible container.
2. The shorter wall limits the water height. Multiply that height by the distance between the walls.
3. Save the area if it is better than the previous best.
4. Keeping the shorter wall and moving the other wall cannot help: the width decreases and the height cannot exceed the same shorter wall.
5. Move the shorter wall instead, hoping to find a taller one.
6. Return the largest area after the pointers meet.

## Example
Example: 1,8,6,2,5,4,8,3,7 -> 49

## Complexity
Time: O(n). Auxiliary space: O(1).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

```c
// Container With Most Water
// Start at both ends. Calculate the area. Move the shorter wall because keeping it cannot improve the area as width decreases.
// O(n) time, O(1) space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
long long solve(int *a, int n) {
    int left=0, right=n-1;
    long long best=0;
    while (left < right) {
        int h = a[left] < a[right] ? a[left] : a[right];
        long long area = (long long)h * (right-left);
        if (area > best) best=area;
        if (a[left] <= a[right]) left++;
        else right--;
    }
    return best;
}
```

## Python
[Python annotated source](../../Python/Ultra_Simple_Commented/003_Container_With_Most_Water.py)

```python
# Container With Most Water
# Start at both ends. Calculate the area. Move the shorter wall because keeping it cannot improve the area as width decreases.
# O(n) time, O(1) space
def solve(a):
    left, right = 0, len(a)-1
    best = 0
    while left < right:
        best = max(best, min(a[left], a[right]) * (right-left))
        if a[left] <= a[right]:
            left += 1
        else:
            right -= 1
    return best
```
