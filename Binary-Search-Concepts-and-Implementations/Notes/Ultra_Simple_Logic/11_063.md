# Lesson 11: Computing Square Roots (#063)

Previous lesson: #066 Search Unknown Length Array

## Mental model
Search largest integer whose square is at most x; use wide arithmetic or division.

## Explain the logic in small steps
1. Search possible integer square roots rather than array elements.
2. A candidate is valid when its square is no larger than x.
3. For a valid candidate, search larger values by moving low to mid + 1.
4. For an invalid candidate, move high to mid - 1.
5. When the search ends, high is the largest valid integer.
6. C uses x / mid to avoid multiplication overflow and starts at 1 to avoid division by zero. Python can multiply safely and starts at 0.

## Example
Example: 27 -> 5

## Complexity
Time: O(log(x+1)). Auxiliary space: O(1).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

```c
// Computing Square Roots
// Search for the greatest integer whose square is at most x. Use division in C to avoid overflow.
// O(log x) time, O(1) space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
int solve(int x) {
    int low=1,high=x;
    while(low<=high) {
        int mid=low+(high-low)/2;
        if(mid<=x/mid) low=mid+1;
        else high=mid-1;
    }
    return high;
}
```

```python
# Computing Square Roots
# Search for the greatest integer whose square is at most x. Use division in C to avoid overflow.
# O(log x) time, O(1) space
def solve(x):
    low,high=0,x
    while low<=high:
        mid=low+(high-low)//2
        if mid*mid<=x: low=mid+1
        else: high=mid-1
    return high
```
