# Lesson 1: Subsets (#049)

Starting foundation.

## Mental model
Record current path; choose each remaining item; recurse with next index; undo choice.

## Explain the logic in small steps
1. Start with an empty path. It is already a valid subset.
2. Save a copy of the path at every recursive call.
3. Try each available element starting at start.
4. Choose the element by placing it at the end of the path.
5. Explore with i + 1 so the same position is not selected twice.
6. Undo the choice before trying a sibling. Python pops; C restores the logical length by returning from recursion.
7. The result contains every subset once for distinct input values.

## Example
Example: 1,2 -> [],[1],[1,2],[2]

## Complexity
Time: O(n*2^n) including output. Auxiliary space: O(n) excluding output.

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

// Subsets
// Save the current path. Choose each remaining element, explore, then undo the choice.
// O(n*2^n) time including output, O(n) auxiliary space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
/* Emit each subset through a callback; callback must copy if retaining it. */
void dfs(int *a,int n,int start,int *path,int depth,void (*emit)(int *,int)) {
    emit(path,depth);
    for(int i=start;i<n;i++) {
        path[depth]=a[i];
        dfs(a,n,i+1,path,depth+1,emit);
    }
}
void solve(int *a,int n,void (*emit)(int *,int)) {
    int *path=malloc((n+1)*sizeof(int));
    dfs(a,n,0,path,0,emit);free(path);
}
```

# Subsets
# Save the current path. Choose each remaining element, explore, then undo the choice.
# O(n*2^n) time including output, O(n) auxiliary space
def solve(a):
    result=[]
    path=[]
    def dfs(start):
        result.append(path.copy())
        for i in range(start,len(a)):
            path.append(a[i])
            dfs(i+1)
            path.pop()
    dfs(0)
    return result
```
