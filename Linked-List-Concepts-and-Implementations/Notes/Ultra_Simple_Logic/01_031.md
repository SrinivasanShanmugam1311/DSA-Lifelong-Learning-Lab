# Lesson 1: Reverse Linked List (#031)

Starting foundation.

## Mental model
Save next; point current to previous; advance previous and current.

## Explain the logic in small steps
1. previous starts empty because the original first node will become the tail.
2. current starts at the head.
3. Save current.next before changing it, or the remaining list would be lost.
4. Point current.next backward to previous.
5. Move previous to current, then move current to the saved next node.
6. When current is empty, previous is the new head.

## Example
Example: 1->2->3 becomes 3->2->1

## Complexity
Time: O(n). Auxiliary space: O(1).

Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

```c
// Reverse Linked List
// Save next before changing the link. Point current backward. Move previous and current forward.
// O(n) time, O(1) space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
typedef struct Node { int val; struct Node *next; } Node;
Node *solve(Node *head) {
    Node *previous=NULL,*current=head;
    while(current) {
        Node *next_node=current->next;
        current->next=previous;
        previous=current;
        current=next_node;
    }
    return previous;
}
```

```python
# Reverse Linked List
# Save next before changing the link. Point current backward. Move previous and current forward.
# O(n) time, O(1) space
class Node:
    def __init__(self,val=0,next=None):
        self.val=val
        self.next=next

def solve(head):
    previous=None
    current=head
    while current:
        next_node=current.next
        current.next=previous
        previous=current
        current=next_node
    return previous
```
