# Lesson 1: Binary Search (#062)

Starting foundation.

## Mental model
Compare middle with target; discard the impossible half.

## Explain the logic in small steps
1. Keep a half-open search range: low is included, high is excluded.
2. Initially high equals the array length, not the last index.
3. Choose the middle index.
4. If its value is smaller than target, all positions through mid are too small. Move low to mid + 1.
5. Otherwise keep mid as a possible first match by setting high to mid.
6. When low equals high, check that the index exists and the value equals target. Otherwise return -1.

## Example
Example: 1,3,5 target 3 -> 1

## Complexity
Time: O(log n). Auxiliary space: O(1).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

```c
// Binary Search
// Find the first value at least target. Check whether it equals target.
// O(log n) time, O(1) space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
int solve(int *a,int n,int target) {
    int low=0,high=n;
    while(low<high) {
        int mid=low+(high-low)/2;
        if(a[mid] < target) low=mid+1;
        else high=mid;
    }
    return low<n && a[low]==target ? low : -1;
}
```

```python
# Binary Search
# Find the first value at least target. Check whether it equals target.
# O(log n) time, O(1) space
def solve(a,target):
    low,high=0,len(a)
    while low<high:
        mid=low+(high-low)//2
        if a[mid] < target: low=mid+1
        else: high=mid
    return low if low < len(a) and a[low] == target else -1
```
