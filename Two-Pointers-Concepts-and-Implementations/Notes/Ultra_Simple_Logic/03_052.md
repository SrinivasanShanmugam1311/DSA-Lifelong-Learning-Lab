# Lesson 3: Two Sum II (#052)

Previous lesson: #001 Remove Duplicates from Sorted Array

## Mental model
Add the two endpoints; increase left for a small sum and decrease right for a large sum.

## Explain the logic in small steps
1. The input must already be sorted.
2. Start with the smallest and largest available values.
3. If their sum equals target, return their one-based positions.
4. If the sum is too small, even the largest available partner cannot help the left value. Move left forward.
5. If the sum is too large, even the smallest available partner cannot help the right value. Move right backward.
6. Stop when the pointers meet; a pair requires two different positions.

## Example
Example: 2,7,11 target 9 -> indices 1,2

## Complexity
Time: O(n). Auxiliary space: O(1).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

// Two Sum II
// Compare the sum of the two ends with target. Move left to increase the sum. Move right to decrease it. Return one-based indices.
// O(n) time, O(1) extra space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
bool solve(int *a,int n,int target,int out[2]) {
    int left=0,right=n-1;
    while(left<right) {
        long long total=(long long)a[left]+a[right];
        if(total==target) {out[0]=left+1;out[1]=right+1;return true;}
        if(total<target) left++; else right--;
    }
    return false;
}
```

# Two Sum II
# Compare the sum of the two ends with target. Move left to increase the sum. Move right to decrease it. Return one-based indices.
# O(n) time, O(1) extra space
def solve(a,target):
    left,right=0,len(a)-1
    while left<right:
        total=a[left]+a[right]
        if total==target: return [left+1,right+1]
        if total<target: left+=1
        else: right-=1
    return []
```
