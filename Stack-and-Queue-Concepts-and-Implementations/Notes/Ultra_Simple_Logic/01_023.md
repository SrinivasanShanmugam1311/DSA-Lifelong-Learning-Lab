# Lesson 1: Valid Parentheses (#023)

Starting foundation.

## Mental model
Push opening brackets; for closing bracket check matching top; accept only empty stack at end.

## Explain the logic in small steps
1. Use a stack to remember opening brackets that have not been closed.
2. Push each opening bracket onto the stack.
3. For a closing bracket, the most recent opening bracket must be its matching type.
4. If the stack is empty or the types differ, return false.
5. Remove the matched opening bracket.
6. At the end the stack must be empty. Input is restricted to the six bracket characters.

## Example
Example: ([]) -> true

## Complexity
Time: O(n). Auxiliary space: O(n).

## TS3 recall
Explain the state you maintain, the condition that changes it, and the stopping rule. Trace the example by hand before coding.

// Valid Parentheses
// Push opening brackets. Each closing bracket must match the last opening bracket. The stack must end empty.
// O(n) time, O(n) space
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <string.h>
#include <ctype.h>
bool solve(const char *s) {
    char *stack=malloc(strlen(s)+1); int top=0;
    for(int i=0;s[i];i++) {
        char ch=s[i];
        if(ch=='(' || ch=='[' || ch=='{') stack[top++]=ch;
        else {
            char want=ch==')'?'(':ch==']'?'[':'{';
            if(top==0 || stack[--top]!=want) {free(stack);return false;}
        }
    }
    bool ok=top==0;free(stack);return ok;
}
```

# Valid Parentheses
# Push opening brackets. Each closing bracket must match the last opening bracket. The stack must end empty.
# O(n) time, O(n) space
def solve(s):
    stack=[]
    pairs={')':'(',']':'[','}':'{'}
    for ch in s:
        if ch in '([{': stack.append(ch)
        elif not stack or stack.pop()!=pairs[ch]: return False
    return not stack
```
